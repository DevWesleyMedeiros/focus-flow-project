# Documento de design do projeto FocusFlow

## Design System
- Paleta de cores: tons de azul para foco, verde para conclusões, vermelho para alertas
- Tipografia: Inter como fonte principal, escala de tamanhos consistente
- Espaçamentos: sistema de 8px base para todos os elementos
- Componentes reutilizáveis: botões, cards, inputs, modais

## Layout das Telas
- Layout responsivo com menu lateral colapsável em mobile
- PWA com suporte a tela cheia e ícones de atalho
- Modo escuro/claro com persistência de preferência

## Animações
- Shader animation no timer principal
- Transições suaves entre navegação de telas
- Animações de conclusão de tarefas
- Notificações com entrada/saída animada
